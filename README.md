# AI Dictionary

**AI terms explained in plain language, for beginners, coders and business people.**

---

## Why this exists

AI is full of words that sound complicated: *token*, *hallucination*, *RAG*, *agent*. Most explanations assume you already know the basics, or skip the basics entirely.

This dictionary starts from zero and goes as deep as you need. Each term is explained in everyday language, with a real example, and a note on what it is easy to confuse with.

## Levels

Every term can be read at a different depth:

| Level | For | Status |
|---|---|---|
| **Beginner** | Anyone new to AI. Everyday language, no code. | Available |
| **Coder** | Developers. How it works, code examples, common pitfalls. | Available |
| **Business** | Founders and managers. Value, cost, when to use it. | Available |
